## 최종 프로젝트 보고서 공개용 사본

마지막으로 다운로드한 `AI13기_파트3_2팀_RFP_RAG_프로젝트_보고서 (3).pdf`를 기준으로 공개용 사본을 갱신했습니다. `(2).pdf`와 같은 바이트이며 이전 원본과는 다릅니다. 검색 시간 p95·최대값·상세 분포 추가, 절 번호 수정, 중복 성과표 정리를 최신 원본 그대로 반영했습니다. 원본은 사용자 PC에 보존했으며 이전 공개본은 Git 이력 `1970520`과 로컬 보존본에 남겼습니다. 공개용 사본에서 7쪽 4.2의 실제 질문·답변 예시를 삭제하고 생략 안내를 넣었습니다. 같은 답변 수치가 반복된 6쪽 마지막 문장도 수치를 제외한 일반 표현으로 바꿨습니다. 가림 상자만 덧씌운 것이 아니라 PDF 본문에서 실제 제거했습니다. 다른 기술 내용·지표·작성자·날짜와 기존 보고서는 변경하지 않았습니다.

독립 텍스트 추출과 주석·메타데이터·첨부·압축 해제 스트림 검사를 통과했고, 23쪽 전체를 렌더링해 확인했습니다. 21쪽은 원본과 픽셀까지 같으며, 수정한 두 쪽도 승인된 영역 밖은 같습니다. [검증 기록](project-report-publication.json)

## 공개용 사본의 정제와 검증

이전에 보류한 세 보고서는 원본을 보존하고 공개용 사본에서 개인 로컬 경로 3곳, 로컬 파일 링크 5개, 문서 Info/XMP 메타데이터만 실제 제거했습니다. 검은 상자로 덮지 않았으며 기술 본문·수치·작성자 표기·본문 날짜는 유지했습니다. 삭제한 경로를 추정한 공개 링크로 바꾸지 않았습니다.

독립 PDF 파서로 경로를 제외한 본문이 같음을 확인했고, 텍스트·객체·압축 해제 스트림·주석에서 개인 경로와 로컬 링크가 남지 않았습니다. 전체 28쪽을 시각 검수했으며 26쪽은 원본과 픽셀까지 같고 나머지 두 쪽도 경로 삭제 영역 밖에는 차이가 없습니다. [정제 검증 기록](public-report-cleanup.json)

**세 보고서의 추가 공개 보류는 해소됐습니다.** 별도 저장소의 운영·접근 상태 및 CLI 전송 승인 점검 문서, 발표 슬라이드·개별 그래프는 기술 보고서 모음의 대상과 구분해 종전처럼 제외합니다. 새 모델 실험·재채점은 하지 않았습니다.
