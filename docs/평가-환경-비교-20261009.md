# 평가 실행 환경 비교

현재 평가 위치는 사용자 PC의 Windows 로컬이다. 기존 VM에서 실행 중이라고 보고하지 않는다. 정상 진행 중인 CPU 평가를 중단하거나 중복 실행하지 않았다.

## 관측한 사실과 제안

| 환경 | 이번에 확인한 사실 | 아직 확인하지 않은 것 | 적합한 다음 용도 |
|---|---|---|---|
| 로컬 CPU | KURE/BGE CPU BF16 캐시 사용, EXAONE CPU 생성 pilot12건 성공, 실제 `size_vram=0`, 4스레드씩 사용 | 전체 검색·생성 완료 및 독립 답변 평가 | 현재 체크포인트 평가를 완료하고 재현 자산 보존 |
| 로컬 RTX 5080 | 16,303MiB, driver610.62. PyTorch2.11.0+cu128에 sm120 포함. 실제 64×64 CUDA 행렬곱 성공, peak allocated8,557,056B, reserved23,068,672B | 실제 새 모델의 GPU 추론·장시간 메모리/사용률 제한·Ollama GPU 적재 | 별도 승인·자원 규칙을 확인한 후 임베딩/리랭킹/생성을 순서대로 실행 |
| 기존 GCP L4 VM | 10월6일 인계에 CPU4·RAM약16GB·L4약23GB, SSH/JupyterHub/PyTorch CUDA 확인 기록 | 이번 작업의 접속·사용률·비용, 프로젝트 LangChain/Chroma/ST/Ollama 준비, 원본/모델 배치 | 프로젝트의 등록 GPU 평가 절차를 준비할 후보 |
| Colab | 기존 후보는 Colab notebook 흐름을 포함. 공식 FAQ에서 GPU 종류·가용량·세션 한도가 유동적임을 확인 | 사용자 계정의 잔여 compute units/구독·이번 GPU 배정·지속 storage·가격 | 짧은 독립 pilot이나 VM 장애 시 후보. 속도 수치를 다른 장비와 직접 비교하지 않기 |

RTX 5080과 현재 PyTorch 빌드의 기본 CUDA 연산 호환성은 실측했다. 이것만으로 BGE·KURE 전체 추론이나 Ollama GPU 실행이 검증되지는 않는다. [Ollama 공식 GPU 목록](https://docs.ollama.com/gpu)은 RTX 5080을 compute capability12.0으로 지원하며, [Windows 문서](https://docs.ollama.com/windows)는 NVIDIA driver 요구사항을 별도로 설명한다. PyTorch 지원과 Ollama 지원은 각각 확인해야 한다. 현재의 정상 CPU 작업을 GPU로 전환하지 않았고 드라이버·라이브러리 대규모 설치도 하지 않았다.

## CPU를 선택한 이유와 시간

Windows 등록 평가 가드는 기존 GPU50% 제한을 보장하지 못하는 실행기를 차단한다. 가드 제거와 등록 인자 생략 대신 공식 Ollama CPU 옵션을 전달하고 관측한 VRAM0을 확인하는 별도 평가 프로토콜을 썼다. `07_verify`의 등록 전체 평가 결과로 표시하지 않는다.

KURE 초기 실측은 약2.0청크/초였다. 메인10,922청크와 후보17,700청크 중 같은 14문서의 기존 벡터3,951개를 검증 후 재사용한다. 나머지24,671청크의 CPU 임베딩, 전체 BGE 재정렬, 생성까지 포함하면 최초의 검색 중심 2~4시간보다 길어진다. 생성 pilot의 처리별 평균은 main34.58초, BGE child33.03초, BGE parent42.78초였다. 504입력 생성만 약5.15시간이라는 단순 추정이며 길이·재생성·동시 CPU 부하에 따라 달라진다. 확정 ETA나 GPU 예상 속도가 아니다.

## 이동 준비와 비용

로컬은 이미 받은 모델 캐시를 재사용하므로 새 모델 다운로드·유료 API 호출은 없다. 원격으로 옮기면 같은 입력·모델·evaluator 해시, Python·torch·tokenizer 버전과 GPU 정밀도를 기록해야 한다. 원문·질문·답변은 비공개 승인된 저장소로만 옮겨야 하며 이번 작업에서는 외부로 전송하지 않았다.

모델 파일만 KURE와 BGE 약4.5GB, EXAONE Ollama 모델 약4.77GB 수준이며, 원문·벡터·기타 runtime을 별도 계산해야 한다. 인계의 VM 디스크 여유14.4GiB는 10월6일 관측치이므로 현재 여유를 보장하지 않는다. 설치·캐시·KV 메모리를 고려하고 동시에 세 모델을 GPU에 올리지 않는 순차 실행을 권한다. GPU 속도·VM 시간당 가격·Colab 잔여 크레딧은 현재 계정과 실행 장비에서 확인하기 전까지 미확인이다. [Colab FAQ](https://research.google.com/colaboratory/faq.html#resource-limits)는 고정 자원 보장을 하지 않는다.

로컬 Ollama API는 [공식 인증 안내](https://docs.ollama.com/api/authentication)에 따라 API 키가 필요 없다. 사용자 API 키 존재 상태와 설정 위치는 로컬 비공개 보고에만 저장했다. 값·부분값·해시를 출력하거나 공개 저장소로 복사하지 않았으며 키 유효성을 확인하는 유료 호출도 하지 않았다.
