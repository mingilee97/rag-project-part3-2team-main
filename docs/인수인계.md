# FINAL-02 인수인계

현재 기본 실행은 FINAL-02입니다. README와 기술 리포트, 출처와 변경을 먼저 읽습니다. `final02.py`는 이전 명령 이름을 유지하는 진입점이며 실제 기능은 `rfp_rag/`에 있습니다.

구버전 실행 폴더와 선택기는 현재 트리에서 제거했습니다. 과거 설명·출처·평가 문서는 `docs/history/`에, 이전 발표와 PDF는 기존 위치에 보존합니다. Git 이력은 교체 전 commit `0f77930191bcb5d5b12c13a8d52d08184154c2f6`에서 이어집니다. 별도 modular 저장소와 운영 VM은 변경 대상이 아닙니다.

검증 명령은 `python -B -m unittest discover -s tests -v`, `python -B -m rfp_rag check`, `git diff --check`입니다. 합성 테스트 12개·원본 동작 비교 6건·함수와 클래스 23개 구조 일치·프롬프트 바이트 일치 및 저장된 결과 300행의 평균 재계산을 확인했습니다. 유료 API·모델 다운로드·전체 성능 재평가는 실행하지 않았습니다.

다른 PC에서는 원본 문서 100건, 정확한 파싱 캐시, 메타데이터, 평가셋, 모델과 본인 키를 별도로 준비해야 합니다. GitHub 코드만으로 비공개 자산을 복원할 수 없습니다. 실제 GPU 환경·새 설치·공급자 API 호환성은 별도 실행 검증 대상입니다.
