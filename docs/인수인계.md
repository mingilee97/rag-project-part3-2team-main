## 추출 과정에서 바꾼 부분

- 검색 모듈에서 평가용 탐색·채점·결과 저장 코드를 제외했다.
- 전처리에 필요한 목차·쪽 번호 판별 함수는 유지하고 EDA 보고서와 평가 코드는 제외했다.
- 평가용 Claude CLI 연결과 채점 설정을 제외했다. local·openai 실행 공급자는 유지했다.
- 개인 컴퓨터에 고정된 데이터 경로를 `data/`로 바꿨다. 상대 경로는 저장소 루트를 기준으로 읽는다.
- 특정 Windows 작업 개체에 자동으로 붙는 초기화는 제외했다. 이 공유판에는 CPU·메모리·GPU 사용량 제한이 없다.
- 기존 데이터에 의존하는 자체 점검은 합성 입력을 쓰는 `test_core.py`로 바꿨다.
- 실행에 직접 사용하는 패키지만 `requirements.txt`에 남겼다.

RAG 검색·답변·근거 검증의 실행 함수는 위 연결과 경로 변경을 제외하고 유지한다. 과거 실험 설정은 공유하지 않으며 최종 실행 설정 `07_verify`만 포함한다.

## 실행과 검사

설치와 실행 명령은 README를 따른다. 변경 후 `python test_core.py`와 `git diff --check`를 실행한다.

2026-10-07 기존 Python 환경에서 `test_core.py`가 통과했다. 모듈 연결, 데이터 경로, PDF 전처리, 청크, 이름 검색, 답변 근거, 약한 근거 거절, 대화 상태를 합성 입력으로 확인했다. 기존 함수·클래스 121개를 비교했고, 119개는 실행 코드가 같으며 2개는 데이터 경로와 공급자 연결 변경이다.

실제 모델·원본 100건의 전체 실행과 새 가상환경의 패키지 설치는 별도 확인이 필요하다. 이 작업에서는 외부 모델을 호출하거나 모델·데이터를 내려받지 않았다.
