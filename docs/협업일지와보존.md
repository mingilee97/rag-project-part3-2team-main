# 협업일지와 VM 종료 후 보존

README는 작성자별 원본 링크를 제공합니다. 일지를 한 사람의 성과로 합치거나 팀원의 원문을 바꾸지 않습니다. 과거 이민기 일지의 9월 30일·10월 2일·10월 6일 요약은 정리용 배치일이며 실제 수행일 미확인이라는 셀 메모를 유지해야 합니다.

프로젝트 종료는 2026년 10월 22일, VM 폐쇄는 10월 26일 예정입니다. 현재 VM과 로컬의 최신 일지·첨부가 동기화됐는지는 확인되지 않았습니다. 이번 코드 정리는 운영 VM에 접속하거나 데이터를 추출하지 않았습니다.

보존 작업에서는 각 작성자의 공식 링크와 내보낸 HTML/Markdown/CSV 및 제출용 PDF를 함께 준비합니다. 작성자·날짜·팀명·본문·원본 URL·내보낸 시각·이미지·첨부파일을 보존하고 파일 목록과 SHA256을 기록합니다. 상대 링크와 이미지는 다른 폴더에 복사한 뒤 오프라인과 정적 HTTP에서 각각 확인합니다. 대시보드 주소만 남기면 VM 종료 후 원문과 첨부를 잃을 수 있습니다.

김현경 Notion은 게스트 열람을 확인했지만 내보내기는 비활성이었습니다. 작성자가 기존 권한으로 내보내 제공하는 방식이 우선입니다. 원본 링크의 평가자 접근과 공유 범위는 따로 확인해야 하며, 링크를 정리했다는 이유로 공개 권한을 넓히지 않습니다.

공개 저장소에는 개인 일지 원문을 임의 복사하지 않습니다. 비공개 내용·연락처·키·개인 일정·원문 RFP를 검사한 보존본만 승인된 위치에 둡니다. 최신 운영 DB와 업로드의 정합 백업·VM 밖 보관·복원은 별도 작업입니다.
