# 승인된 중간발표 자료

슬라이드 PDF 9쪽, 발표자노트 PDF 11쪽 및 승인된 HTML 두 파일을 원본 바이트 그대로 보존했습니다. source-manifest.json의 해시로 원본과 비교할 수 있습니다.

발표 자료는 기존 평가 시점 구성입니다. 배포 실행 기본은 Claude Haiku 4.5이며 동일조건 품질 재평가 전입니다. 발표 본문을 Haiku의 성능 성과로 수정하지 않았습니다. 발표 속 새 기초 파이프라인 예시는 실제 RFP 성공 사례가 아닌 합성 설명입니다. 기존 modular 저장소를 이 저장소에 병합하지 않았습니다.
